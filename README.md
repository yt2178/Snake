# 🐍 Snake Pro - Nokia Edition

A professional, high-performance Nokia-style Snake game optimized for **Android 4.4 (KitKat)** and above. Designed specifically for smart feature phones and small-screen devices.

[עברית למטה]

## 🚀 Key Features

- **🎮 Dual Input Support:**
    - **Touch Devices:** Responsive swipe gestures for modern phones (like Jelly 2).
    - **Physical Keypads:** Full support for D-Pad, Soft Keys (Menu/Back), and T9 number keys (2,4,6,8,5) for devices like **Qin 1S+**.
- **📱 Responsive Display:** Automatically scales UI and game grid for any resolution (from 240x320 to HD).
- **🏆 Advanced High Score System:** Saves and displays your **Top 5** records with a themed podium (Gold, Silver, Bronze).
- **🗺️ Challenging Maps:** 6 unique maps including Classic, Box, Tunnel, Mill, Rails, and Apartment.
- **🍎 Golden Bonus Apple:**
    - Appears with a 20% chance.
    - Dynamic score based on remaining time (up to 5 points).
    - 5-second countdown with a visual progress bar and digital timer.
- **🇮🇱 Bilingual Interface:** Seamless toggle between **Hebrew (RTL)** and **English (LTR)** with full UI adjustment.
- **💎 Retro-Premium Graphics:**
    - Graduated backgrounds and textured tiles.
    - Dynamic snake face (eyes and smile) that follows movement direction.
    - Animated "glow" and "pulse" effects for food.
- **💾 Game Persistence:** Automatically saves progress to resume after closing the app.

## 🛠️ Technical Specifications

- **Compatibility:** Optimized for **API 19 (Android 4.4 KitKat)**.
- **Engine:** Built on `SurfaceView` with a dedicated game loop thread for a steady **60 FPS** even on low-end hardware.
- **Compatibility Layers:** Custom `drawRoundRectCompat` and vibration handlers for backward compatibility.
- **Full Screen:** Implements `IMMERSIVE_STICKY` mode for a focused gaming experience.
